# YOUSEF AI لـ VS Code

يوسف داخل محررك. يتصل بخادم يوسف المحلي على جهازك (شغّله بـ `start.bat`)، فتعمل كل النماذج والذاكرة والإعدادات نفسها التي في لوحة يوسف.

## ماذا تفعل

| الطريقة | النتيجة |
|---|---|
| أيقونة يوسف في الشريط الجانبي (أو Ctrl+Alt+Y) | لوحة محادثة ترسل طلبك مع الملف المفتوح أو الكود المحدد |
| الزر الأيمن في المحرر ← «يوسف: اشرح هذا» | شرح الكود المحدد أو الملف |
| الزر الأيمن ← «يوسف: أصلح هذا» | يبحث يوسف عن الأخطاء ويقترح تعديلات |
| الزر الأيمن ← «يوسف: اسأل عن هذا الكود» (Ctrl+Alt+U) | سؤالك أنت عن التحديد |

## التعديلات

- **قبل أي قراءة:** يسألك يوسف أول مرة إن كان مسموحًا له بقراءة مجلد المشروع.
- **التعديلات اقتراحات:** كل ملف مقترح يظهر في اللوحة مع زر «اعرض الفرق»، الذي يفتح محرر الفروقات في VS Code.
- **لا كتابة بدون موافقة:** لا يُكتب أي ملف إلا بعد «طبّق التعديلات». إن عدّلت الملف بنفسك بعد الاقتراح، لا يكتب يوسف فوقه.
- **ملفات الأسرار:** `.env` والمفاتيح و`wp-config.php` لا تُقرأ أبدًا.

## الإعداد

`yousef.serverUrl`: عنوان الخادم، والافتراضي `http://127.0.0.1:8765`.
