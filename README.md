# YOUSEF AI — المرحلة 1: النواة

وكيل شخصي متعدد الوكلاء يعمل على ويندوز. يقسّم طلبك إلى خطوات، ويوزّعها على وكلاء متخصصين، ويختار لكل خطوة النموذج المناسب: محلي عبر Ollama، أو سحابي عبر Claude أو OpenAI أو Gemini.

## التشغيل بنقرة

1. ثبّت **Python 3.10 أو أحدث** من [python.org](https://www.python.org/downloads/)، وفعّل خيار **Add python.exe to PATH** أثناء التثبيت.
2. ثبّت **Ollama** من [ollama.com](https://ollama.com) وشغّله، ثم ثبّت نموذجًا من الطرفية:
   ```
   ollama pull qwen2.5:7b
   ```
   هذا النموذج يناسب كرت GTX 1660 Super (ذاكرة 6GB) ويفهم العربية جيدًا.
3. انقر مرتين على **`start.bat`**. تفتح لوحة التحكم في المتصفح على `http://127.0.0.1:8765`.
4. اختياري: انقر على **`create-shortcut.bat`** مرة واحدة لوضع اختصار «YOUSEF AI» على سطح المكتب.

لا توجد حزم لتثبيتها: النواة مبنية على مكتبات بايثون القياسية فقط، فتعمل بدون إنترنت مع Ollama.

إن نقرت `start.bat` وهو يعمل أصلًا، يفتح اللوحة فقط ولا يشغّل نسخة ثانية.

## إضافة النماذج السحابية (اختياري)

من **الإعدادات ← النماذج السحابية**: الصق مفتاح API، ثم اضغط «اجلب النماذج» واختر النموذج.

- **المفاتيح:** تُشفَّر بتقنية DPAPI المرتبطة بحساب ويندوز الخاص بك. لا تغادر جهازك، ولا تُعرض في اللوحة بعد حفظها، ولا يستطيع مستخدم آخر على الجهاز نفسه قراءتها.
- **وضع «محلي فقط»:** يمنع أي اتصال بالسحابة، فلا يخرج شيء من جهازك.

## كيف يختار النموذج

لكل نوع مهمة توجيه تعدّله من الإعدادات:

| نوع المهمة | الافتراضي |
|---|---|
| المحادثة والأسئلة | محلي أولًا |
| تخطيط الخطوات | محلي أولًا |
| البرمجة | سحابي أولًا |
| التحليل | سحابي أولًا |
| الكتابة والمحتوى | سحابي أولًا |

- **عند الفشل:** إن تعطّل النموذج الأول، يجرّب التالي تلقائيًا.
- **بدون مفاتيح:** كل شيء يعمل محليًا.

## التعلّم

- **القواعد:** أضفها من الإعدادات، مثل «اكتب منشورات المتجر بلهجة عُمانية». تُعطى لكل الوكلاء في كل طلب.
- **التقييم:** بعد كل إجابة اضغط «أفادت» أو «لم تُفد» مع ملاحظة. يتذكّر يوسف ذلك في الطلبات المشابهة.

هذا تعلّم بالذاكرة، لا إعادة تدريب للنموذج.

## أين تُحفظ بياناتك

في `%LOCALAPPDATA%\YousefAI`، منفصلة لكل مستخدم ويندوز:

| الملف | المحتوى |
|---|---|
| `memory.db` | المهام، الخطوات، الدروس |
| `settings.json` | الإعدادات (بدون مفاتيح) |
| `keys.dat` | المفاتيح المشفّرة |
| `yousef.log` | سجل التشغيل لتتبع الأخطاء |

## خيارات التشغيل

```
start.bat --port 8780      منفذ آخر
start.bat --no-browser     بدون فتح المتصفح
start.bat --debug          سجل مفصّل
```

## هيكل المشروع

```
yousef/
  __main__.py        نقطة التشغيل
  app.py             ربط المكوّنات
  config.py          الإعدادات ومجلد البيانات
  keystore.py        تخزين المفاتيح المشفّر (DPAPI)
  memory.py          الذاكرة (SQLite)
  server.py          الخادم المحلي وواجهة API
  models/
    providers.py     Ollama وClaude وOpenAI وGemini
    router.py        موجّه النماذج
  core/
    orchestrator.py  المنسّق والمخطّط
    agents.py        الوكلاء
    permissions.py   بوابة الموافقة
  web/               لوحة التحكم
tests/               الاختبارات
```

لتشغيل الاختبارات:

```
python -m unittest discover -s tests
```

## الأمان

- **الشبكة:** الخادم يستمع على `127.0.0.1` فقط، فلا يصل إليه أي جهاز آخر على الشبكة.
- **المواقع الأخرى:** الطلبات التي تغيّر شيئًا تحتاج ترويسة خاصة، والخادم يرفض أي عنوان أو مصدر غريب. هذا يمنع أي موقع آخر مفتوح في المتصفح من التحكم بيوسف.
