# YOUSEF AI

وكيل شخصي متعدد الوكلاء يعمل على ويندوز. يقسّم طلبك إلى خطوات، ويوزّعها على وكلاء متخصصين، ويختار لكل خطوة النموذج المناسب: محلي عبر Ollama، أو سحابي عبر Claude أو OpenAI أو Gemini.

## التشغيل بنقرة

1. ثبّت **Python 3.10 أو أحدث** من [python.org](https://www.python.org/downloads/)، وفعّل خيار **Add python.exe to PATH** أثناء التثبيت.
2. ثبّت **Ollama** من [ollama.com](https://ollama.com) وشغّله، ثم ثبّت نموذجًا من الطرفية:
   ```
   ollama pull qwen2.5:7b
   ```
   هذا النموذج يناسب كرت GTX 1660 Super (ذاكرة 6GB) ويفهم العربية جيدًا.
3. انقر مرتين على **`start.bat`**. تفتح لوحة التحكم في المتصفح على `http://127.0.0.1:8765`.
4. اختياري: انقر على **`create-shortcut.bat`** مرة واحدة لوضع اختصار «YOUSEF AI» على سطح المكتب.

لا توجد حزم لتثبيتها: النواة مبنية على مكتبات بايثون القياسية فقط، فتعمل بدون إنترنت مع Ollama.

إن نقرت `start.bat` وهو يعمل أصلًا، يفتح اللوحة فقط ولا يشغّل نسخة ثانية.

## إضافة النماذج السحابية (اختياري)

من **الإعدادات ← النماذج السحابية**: الصق مفتاح API، ثم اضغط «اجلب النماذج» واختر النموذج.

- **المفاتيح:** تُشفَّر بتقنية DPAPI المرتبطة بحساب ويندوز الخاص بك. لا تغادر جهازك، ولا تُعرض في اللوحة بعد حفظها، ولا يستطيع مستخدم آخر على الجهاز نفسه قراءتها.
- **وضع «محلي فقط»:** يمنع أي اتصال بالسحابة، فلا يخرج شيء من جهازك.

## الصوت (اختياري)

تحدّث مع يوسف بالعربية أو الإنجليزية. التعرّف على الكلام يعمل على جهازك بنموذج Whisper، والصوت لا يغادر الجهاز.

**التفعيل مرة واحدة:**
1. انقر **`install-voice.bat`**. يثبّت `faster-whisper` في مجلد `.venv` داخل المشروع، ويحتاج الإنترنت هذه المرة فقط.
2. شغّل `start.bat` كالمعتاد؛ يستخدم بيئة الصوت تلقائيًا.
3. أول استخدام ينزّل نموذج الكلام (حوالي 500MB لنموذج `small`)، ثم يعمل بدون إنترنت.

**طرق الكلام:**

| الطريقة | كيف |
|---|---|
| اضغط وتكلّم | زر الميكروفون بجانب «أرسل». تكلّم، ويُرسل الطلب عندما تسكت |
| الاستماع الدائم | زر «الاستماع الدائم» أعلى الصفحة. قل «يوسف» ثم طلبك، أو قل «يوسف» وانتظر الصفارة ثم تكلّم |
| الموافقة بالصوت | إن احتاجت خطوة موافقتك، يسألك يوسف بصوت؛ قل «وافق» أو «ارفض» |

- **قراءة الردود:** ردود الطلبات الصوتية تُقرأ بأصوات ويندوز المحلية. لصوت عربي: إعدادات ويندوز ← الوقت واللغة ← الكلام ← أضف صوتًا عربيًا. متصفح Edge يوفّر أصواتًا عربية أوضح عبر الإنترنت إن سمحت بها من الإعدادات.
- **النموذج والمعالج:** من **الإعدادات ← الصوت**. الافتراضي `small` على المعالج، لأن ذاكرة كرت الشاشة يستخدمها Ollama. `medium` أدق للعربية لكنه أبطأ.
- **كلمات التنبيه:** قابلة للتغيير من الإعدادات.
- **حدود الاستماع الدائم:** يعمل ما دامت صفحة يوسف مفتوحة في المتصفح (ولو في الخلفية).

## المبرمج يعمل على مشاريعك

أضف مجلد مشروعك من **الإعدادات ← مجلدات المشاريع**، ثم اختره من «المشروع» أسفل خانة الطلب.

- **ماذا يفعل:** يتصفح المبرمج الملفات ويقرأها ويبحث فيها، ثم يقترح التعديلات كفروقات ملوّنة.
- **قبل أي كتابة:** لا يُكتب أي ملف إلا بعد «طبّق التعديلات». وإن عدّلت ملفًا بنفسك بعد الاقتراح، لا يكتب يوسف فوقه.
- **حدود القراءة:** لا يقرأ يوسف خارج المجلدات التي سمحت بها، ولا ملفات الأسرار (`.env`، المفاتيح، الشهادات، `wp-config.php`)، ولا `.git` و`node_modules`.

### Git وGitHub وVercel

| الأداة | ما يحتاجه | متى ينفّذ |
|---|---|---|
| حالة git وفروقاته | المجلد مستودع git | فورًا (قراءة فقط) |
| commit، ثم push | git مثبّت على جهازك؛ الرفع بصلاحياتك الحالية في git | بعد «طبّق الكل»، وبهذا الترتيب: الملفات ثم commit ثم push |
| فتح Pull Request | رمز GitHub من **الإعدادات ← GitHub وVercel**، والمستودع على github.com | بعد push |
| حالة النشر على Vercel وأخطاء البناء | رمز Vercel (قراءة)، واسم المشروع في إعدادات المجلد | فورًا (قراءة فقط) |
| تشغيل أوامر مثل `npm test` | تضيفها بنفسك في «الأوامر وVercel» لكل مشروع | فورًا، والأوامر غير المسموحة تُرفض |

- **«الملفات فقط»:** يكتب التعديلات بدون commit أو push.
- **النشر:** Vercel يبني كل commit يُرفع، فلا يحتاج يوسف صلاحية نشر مباشرة.

## مدير المتاجر (Shopify وWooCommerce)

أضف متجرك من **الإعدادات ← المتاجر ← أضف متجرًا**. يختبر يوسف الاتصال أولًا، ولا يحفظ المتجر إن فشل.

| المنصة | ما تحتاجه |
|---|---|
| Shopify | رابط المتجر (`my-shop.myshopify.com`)، ورمز Admin API من «الإعدادات ← التطبيقات ← طوّر تطبيقًا» بصلاحيات `read_products` و`write_products` و`read_orders` |
| WooCommerce | رابط الموقع بـ https، ومفتاحا REST API (consumer key وconsumer secret) بصلاحية «قراءة/كتابة» من «WooCommerce ← الإعدادات ← متقدم ← REST API» |

بعدها اطلب ما تريد، مثل «راجع مبيعات الشهر واقترح أسعارًا للعود» أو «أضف مبخرة فخارية بسعر 4.5». يمكنك اختيار متجر محدد من «المتجر» أسفل خانة الطلب.

- **ما يقرأه:** المنتجات، والطلبات (أرقام ومنتجات وحالات فقط)، وملخص المبيعات.
- **ما يقترحه:** منتجات جديدة، وتعديل العنوان والوصف والسعر وSKU والوسوم والحالة. كل اقتراح بطاقة فيها القيم «قبل» و«بعد»، مع تنبيه إن تغيّر سعر أكثر من 50% أو صار صفرًا.
- **الموافقة:** أزل العلامة عن أي اقتراح لا تريده، ثم «طبّق المحدد». المنتجات الجديدة تُنشأ **مسودة** إلا إن طلبت نشرها صراحة.
- **الحماية من التعارض:** إن تغيّر المنتج في المتجر بعد الاقتراح، لا يكتب يوسف فوقه ويعرض «تعارض».
- **ما لا يفعله:** لا يحذف منتجات، ولا يردّ مبالغ، ولا يعدّل طلبات، ولا يقرأ أسماء العملاء أو بريدهم أو عناوينهم أو هواتفهم.

## يوسف داخل VS Code

1. انقر **`install-vscode-extension.bat`**. يبني ملف `dist\yousef-ai.vsix` ويثبّته في VS Code.
   - إن لم يجد الأمر `code`: من VS Code افتح Extensions، ثم «...»، ثم **Install from VSIX**، واختر الملف.
2. أبقِ يوسف شغّالًا (`start.bat`)، ثم اضغط أيقونة يوسف في الشريط الجانبي (أو Ctrl+Alt+Y).

| داخل VS Code | النتيجة |
|---|---|
| لوحة يوسف الجانبية | محادثة تُرسل الملف المفتوح أو الكود المحدد مع طلبك |
| الزر الأيمن ← «يوسف: اشرح هذا» / «أصلح هذا» / «اسأل عن هذا الكود» | أوامر سريعة على التحديد أو الملف |
| «اعرض الفرق» | يفتح محرر الفروقات في VS Code بين الملف والاقتراح |
| «طبّق التعديلات» | يكتب يوسف الملفات، ويحدّثها VS Code تلقائيًا |

أول مرة يسألك يوسف إن كان مسموحًا له بالعمل على مجلد المشروع. الإضافة لا تحتوي ذكاءً بداخلها: كل شيء يمر عبر خادم يوسف المحلي بنفس النماذج والذاكرة والإعدادات.

## كيف يختار النموذج

لكل نوع مهمة توجيه تعدّله من الإعدادات:

| نوع المهمة | الافتراضي |
|---|---|
| المحادثة والأسئلة | محلي أولًا |
| تخطيط الخطوات | محلي أولًا |
| البرمجة | سحابي أولًا |
| التحليل | سحابي أولًا |
| الكتابة والمحتوى | سحابي أولًا |

- **عند الفشل:** إن تعطّل النموذج الأول، يجرّب التالي تلقائيًا.
- **بدون مفاتيح:** كل شيء يعمل محليًا.

## الوكلاء الآن

| الوكيل | عمله | ينفّذ فعلًا؟ |
|---|---|---|
| المساعد العام | أسئلة، شرح، تلخيص، نصائح | لا |
| المبرمج | كتابة الكود وإصلاحه؛ مع مجلد مشروع: قراءة الملفات وتعديلها وgit وPull Requests | نعم، بعد موافقتك |
| مدير المتاجر | مع متجر متصل: المنتجات والطلبات والمبيعات، واقتراح منتجات وتعديلات | نعم، بعد موافقتك |
| صانع المحتوى | منشورات، إعلانات، وصف منتجات، سكربتات فيديو | لا (النشر في المرحلة 5) |
| المحلل | مقارنة العملاء والمنافسين والأسواق | لا |

أي إجراء خارج المحادثة (كتابة ملفات، git، تغيير متجر، نشر، إرسال، دفع، حذف) لا يُنفَّذ قبل موافقتك.

## التعلّم

- **القواعد:** أضفها من الإعدادات، مثل «اكتب منشورات المتجر بلهجة عُمانية». تُعطى لكل الوكلاء في كل طلب.
- **التقييم:** بعد كل إجابة اضغط «أفادت» أو «لم تُفد» مع ملاحظة. يتذكّر يوسف ذلك في الطلبات المشابهة.

هذا تعلّم بالذاكرة، لا إعادة تدريب للنموذج.

## أين تُحفظ بياناتك

في `%LOCALAPPDATA%\YousefAI`، منفصلة لكل مستخدم ويندوز:

| الملف | المحتوى |
|---|---|
| `memory.db` | المهام، الخطوات، الدروس |
| `settings.json` | الإعدادات (بدون مفاتيح) |
| `keys.dat` | المفاتيح المشفّرة |
| `yousef.log` | سجل التشغيل لتتبع الأخطاء |

## الأمان

- **الشبكة:** الخادم يستمع على `127.0.0.1` فقط، فلا يصل إليه أي جهاز آخر على الشبكة.
- **المواقع الأخرى:** الطلبات التي تغيّر شيئًا تحتاج ترويسة خاصة، والخادم يرفض أي عنوان أو مصدر غريب. هذا يمنع أي موقع آخر مفتوح في المتصفح من التحكم بيوسف.
- **الميكروفون:** الصوت يُرسل فقط إلى خادم يوسف المحلي على جهازك.
