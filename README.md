# YOUSEF AI

وكيل شخصي متعدد الوكلاء يعمل على ويندوز. يقسّم طلبك إلى خطوات، ويوزّعها على وكلاء متخصصين، ويختار لكل خطوة النموذج المناسب: محلي عبر Ollama، أو سحابي عبر Claude أو OpenAI أو Gemini.

## التشغيل بنقرة

1. ثبّت **Python 3.10 أو أحدث** من [python.org](https://www.python.org/downloads/)، وفعّل خيار **Add python.exe to PATH** أثناء التثبيت.
2. ثبّت **Ollama** من [ollama.com](https://ollama.com) وشغّله، ثم ثبّت نموذجًا من الطرفية:
   ```
   ollama pull qwen2.5:7b
   ```
   هذا النموذج يناسب كرت GTX 1660 Super (ذاكرة 6GB) ويفهم العربية جيدًا.
3. انقر مرتين على **`start.bat`**. تفتح لوحة التحكم في المتصفح على `http://127.0.0.1:8765`.
4. اختياري: انقر على **`create-shortcut.bat`** مرة واحدة لوضع اختصار «YOUSEF AI» على سطح المكتب.

لا توجد حزم لتثبيتها: النواة مبنية على مكتبات بايثون القياسية فقط، فتعمل بدون إنترنت مع Ollama.

إن نقرت `start.bat` وهو يعمل أصلًا، يفتح اللوحة فقط ولا يشغّل نسخة ثانية.

## إضافة النماذج السحابية (اختياري)

من **الإعدادات ← النماذج السحابية**: الصق مفتاح API، ثم اضغط «اجلب النماذج» واختر النموذج.

- **المفاتيح:** تُشفَّر بتقنية DPAPI المرتبطة بحساب ويندوز الخاص بك. لا تغادر جهازك، ولا تُعرض في اللوحة بعد حفظها، ولا يستطيع مستخدم آخر على الجهاز نفسه قراءتها.
- **وضع «محلي فقط»:** يمنع أي اتصال بالسحابة، فلا يخرج شيء من جهازك.

## الصوت (اختياري)

تحدّث مع يوسف بالعربية أو الإنجليزية. التعرّف على الكلام يعمل على جهازك بنموذج Whisper، والصوت لا يغادر الجهاز.

**التفعيل مرة واحدة:**
1. انقر **`install-voice.bat`**. يثبّت `faster-whisper` في مجلد `.venv` داخل المشروع، ويحتاج الإنترنت هذه المرة فقط.
2. شغّل `start.bat` كالمعتاد؛ يستخدم بيئة الصوت تلقائيًا.
3. أول استخدام ينزّل نموذج الكلام (حوالي 1.6GB لنموذج `large-v3-turbo`)، ثم يعمل بدون إنترنت.
4. اختياري، لسرعة أكبر بكثير على كرت NVIDIA: انقر **`install-voice-gpu.bat`** (حوالي 1GB من مكتبات NVIDIA، بدون تثبيت CUDA)، ثم اختر «كرت الشاشة» في **الإعدادات ← الصوت**. إن تعذّر استخدام الكرت يعمل يوسف على المعالج ويخبرك بالسبب.

**طرق الكلام:**

| الطريقة | كيف |
|---|---|
| اضغط وتكلّم | زر الميكروفون بجانب «أرسل». تكلّم، ويُرسل الطلب عندما تسكت |
| الاستماع الدائم | زر «الاستماع الدائم» أعلى الصفحة. قل «يوسف» ثم طلبك، أو قل «يوسف» وانتظر الصفارة ثم تكلّم |
| الموافقة بالصوت | إن احتاجت خطوة موافقتك، يسألك يوسف بصوت؛ قل «وافق» أو «ارفض» |

- **العربية:** النماذج الصغيرة (`small` وما دونها) تخطئ كثيرًا في العربية، خاصة اللهجة الخليجية؛ استخدم `large-v3-turbo` (الافتراضي من 0.6.1). وضع «تلقائي» يختار بين العربية والإنجليزية فقط، فلا يقرأ كلامك العربي كفارسي أو أردو. وإن كنت تتكلم العربية دائمًا فاختر «العربية فقط» لدقة أعلى.
- **قراءة الردود:** تُقرأ بأصوات المتصفح. أوضح صوت عربي: افتح يوسف في **Microsoft Edge** وفعّل «الأصوات عبر الإنترنت» من **الإعدادات ← الصوت** (أصوات طبيعية مجانية، منها العُمانية)، ثم اختر الصوت واضغط «جرّب الصوت». أو أضف صوتًا عربيًا محليًا من ويندوز: الإعدادات ← الوقت واللغة ← الكلام.
- **النموذج والمعالج:** من **الإعدادات ← الصوت**. على المعالج يأخذ `large-v3-turbo` بضع ثوانٍ لكل أمر، وعلى كرت الشاشة أقل من ثانية.
- **كلمات التنبيه:** قابلة للتغيير من الإعدادات.
- **حدود الاستماع الدائم:** يعمل ما دامت صفحة يوسف مفتوحة في المتصفح (ولو في الخلفية).

## المبرمج يعمل على مشاريعك

أضف مجلد مشروعك من **الإعدادات ← مجلدات المشاريع**، ثم اختره من «المشروع» أسفل خانة الطلب.

- **ماذا يفعل:** يتصفح المبرمج الملفات ويقرأها ويبحث فيها، ثم يقترح التعديلات كفروقات ملوّنة.
- **قبل أي كتابة:** لا يُكتب أي ملف إلا بعد «طبّق التعديلات». وإن عدّلت ملفًا بنفسك بعد الاقتراح، لا يكتب يوسف فوقه.
- **حدود القراءة:** لا يقرأ يوسف خارج المجلدات التي سمحت بها، ولا ملفات الأسرار (`.env`، المفاتيح، الشهادات، `wp-config.php`)، ولا `.git` و`node_modules`.

### Git وGitHub وVercel

| الأداة | ما يحتاجه | متى ينفّذ |
|---|---|---|
| حالة git وفروقاته | المجلد مستودع git | فورًا (قراءة فقط) |
| commit، ثم push | git مثبّت على جهازك؛ الرفع بصلاحياتك الحالية في git | بعد «طبّق الكل»، وبهذا الترتيب: الملفات ثم commit ثم push |
| فتح Pull Request | رمز GitHub من **الإعدادات ← GitHub وVercel**، والمستودع على github.com | بعد push |
| حالة النشر على Vercel وأخطاء البناء | رمز Vercel (قراءة)، واسم المشروع في إعدادات المجلد | فورًا (قراءة فقط) |
| تشغيل أوامر مثل `npm test` | تضيفها بنفسك في «الأوامر وVercel» لكل مشروع | فورًا، والأوامر غير المسموحة تُرفض |

- **«الملفات فقط»:** يكتب التعديلات بدون commit أو push.
- **النشر:** Vercel يبني كل commit يُرفع، فلا يحتاج يوسف صلاحية نشر مباشرة.

## مدير المتاجر (Shopify وWooCommerce)

أضف متجرك من **الإعدادات ← المتاجر ← أضف متجرًا**. يختبر يوسف الاتصال أولًا، ولا يحفظ المتجر إن فشل.

| المنصة | ما تحتاجه |
|---|---|
| Shopify | رابط المتجر (`my-shop.myshopify.com`)، ورمز Admin API من «الإعدادات ← التطبيقات ← طوّر تطبيقًا» بصلاحيات `read_products` و`write_products` و`read_orders`، وللعروض وأكواد الخصم أيضًا `read_discounts` و`write_discounts` |
| WooCommerce | رابط الموقع بـ https، ومفتاحا REST API (consumer key وconsumer secret) بصلاحية «قراءة/كتابة» من «WooCommerce ← الإعدادات ← متقدم ← REST API» |

بعدها اطلب ما تريد، مثل «راجع مبيعات الشهر واقترح أسعارًا للعود» أو «أضف مبخرة فخارية بسعر 4.5». يمكنك اختيار متجر محدد من «المتجر» أسفل خانة الطلب.

- **ما يقرأه:** المنتجات، والطلبات (أرقام ومنتجات وحالات فقط)، وملخص المبيعات.
- **ما يقترحه:** منتجات جديدة، وتعديل العنوان والوصف والسعر وSKU والوسوم والحالة (وفي Shopify عنوان ووصف البحث SEO، وفي WooCommerce سعر تخفيض مجدول ببداية ونهاية). كل اقتراح بطاقة فيها القيم «قبل» و«بعد»، مع تنبيه إن تغيّر سعر أكثر من 50% أو صار صفرًا.
- **العروض:** خصم بنسبة أو بمبلغ، على منتجات محددة أو على الطلب كله، بكود (مثل `AUTUMN15`) أو تلقائي في Shopify، ببداية ونهاية وحد أدنى للطلب وحد للاستخدام أو مرة لكل عميل. في WooCommerce العروض كوبونات بكود دائمًا. ويستطيع إيقاف عرض قائم.
- **الباقات:** يجمع عدة منتجات بكمياتها في منتج واحد بسعر واحد، ويعرض كم يوفّر العميل. في Shopify باقة أصلية مخزونها من مكوّناتها؛ وفي WooCommerce منتج بسيط يذكر مكوّناته (مخزونه منفصل، وتنبّهك البطاقة لذلك). الباقة تُنشأ مسودة.
- **الموافقة:** أزل العلامة عن أي اقتراح لا تريده، ثم «طبّق المحدد». المنتجات الجديدة تُنشأ **مسودة** إلا إن طلبت نشرها صراحة.
- **الحماية من التعارض:** إن تغيّر المنتج في المتجر بعد الاقتراح، لا يكتب يوسف فوقه ويعرض «تعارض».
- **ما لا يفعله:** لا يحذف منتجات، ولا يردّ مبالغ، ولا يعدّل طلبات، ولا يقرأ أسماء العملاء أو بريدهم أو عناوينهم أو هواتفهم.

## المدير التقني (فحص الثغرات والأخطاء وإصلاحها)

اطلب مثل «افحص متجري» أو «افحص كود المشروع وأصلح الثغرات». يعمل مع متجر متصل أو مجلد مشروع أو الاثنين.

| الفحص | ماذا يفحص |
|---|---|
| موقع المتجر الحي | HTTPS وتحويل http، صلاحية الشهادة، ترويسات الأمان، ملفات مكشوفة للعامة (`.env`، `.git`، نسخ `wp-config`، سجلات الأخطاء، phpinfo)، وفي ووردبريس: xmlrpc وكشف أسماء المستخدمين وفهرسة المجلدات، المحتوى المختلط، السرعة، وأساسيات SEO (العنوان، الوصف، H1، alt، sitemap، robots.txt) |
| صحة المتجر | منتجات منشورة بسعر صفر أو بلا صورة أو وصف أو SKU، وSKU مكرر؛ وفي WooCommerce: إصدارات ووردبريس وPHP، وضع التصحيح، الإضافات والقالب غير المحدّثة |
| كود المشروع | مفاتيح وكلمات مرور مكتوبة في الكود، حقن SQL، XSS، eval، رفع ملفات غير آمن، معالجات AJAX بلا nonce، تعطيل التحقق من TLS، وغيرها في PHP وJavaScript وPython |
| الحزم | ثغرات معروفة (CVE) في حزم `package-lock.json` و`composer.lock` و`requirements.txt` من قاعدة OSV المفتوحة |

- **الإصلاح:** يؤكد كل مشكلة بقراءة الكود، ثم يقترح تعديلات الملفات كفروقات وتعديلات بيانات المتجر كبطاقات، في موافقة واحدة. وما لا تصله أدواته (إعدادات الاستضافة، تحديث الإضافات، إصدار PHP) يكتب لك خطواته بالتحديد.
- **التقرير:** مرتب حسب الخطورة: حرج، عالٍ، متوسط، منخفض.
- **حدوده:** يفحص مواقع متاجرك المتصلة ومجلداتك المسموحة فقط، بطلبات قراءة قليلة؛ لا يخمّن كلمات مرور ولا يستغل ثغرة ولا يفحص مواقع غيرك. إن وجد ملفًا مكشوفًا لا يقرأ محتواه، ويكتفي بأنه مكشوف.
- **أسرارك:** المفاتيح المكتوبة داخل الملفات لا تصل إلى أي نموذج؛ يراها النموذج علامة مثل `[[SECRET_1]]`، وتعود القيمة الحقيقية داخل تعديلاته فقط. فحص الحزم يرسل أسماء الحزم وإصداراتها فقط، لا الكود.

## ناشر السوشيال (فيسبوك وإنستغرام)

يكتب يوسف منشوراتك وينشرها أو يجدولها على صفحات فيسبوك وحسابات إنستغرام التجارية المرتبطة بها، عبر واجهة Meta الرسمية. لا يُنشر شيء قبل موافقتك.

**الربط مرة واحدة** (من **الإعدادات ← حسابات السوشيال ← اربط صفحاتك**):
1. من `developers.facebook.com` أنشئ تطبيقًا خاصًا بك. يكفي «وضع التطوير» للنشر على صفحاتك أنت.
2. من **Graph API Explorer** اختر تطبيقك، ثم «User Token»، وفعّل الصلاحيات: `pages_show_list` و`pages_read_engagement` و`pages_manage_posts` و`instagram_basic` و`instagram_content_publish` و`business_management`، ثم «Generate Access Token».
3. افتح الرمز في **Access Token Debugger** واضغط «Extend Access Token»، ثم الصق الرمز الطويل في يوسف.

يجلب يوسف صفحاتك ورمز كل صفحة (لا تنتهي صلاحيته ما دام مشتقًا من رمز طويل)، ويحفظها مشفّرة. حساب إنستغرام يجب أن يكون تجاريًا أو حساب صانع محتوى ومرتبطًا بالصفحة.

**الاستخدام:** اطلب مثل «انشر عرض الخريف على العود في فيسبوك وإنستغرام» أو «جدول تذكيرًا غدًا 7 مساءً». لإرفاق صورك اضغط زر الصورة بجانب الميكروفون أو اسحبها إلى خانة الطلب.

| | فيسبوك | إنستغرام |
|---|---|---|
| المحتوى | نص، رابط، صورة أو عدة صور | صورة أو ألبوم حتى 10 صور (الصورة إلزامية) |
| النص | طويل | حتى 2200 حرف و30 وسمًا و20 إشارة؛ الروابط غير قابلة للنقر |
| الجدولة | يحتفظ بها فيسبوك نفسه (من 10 دقائق إلى 30 يومًا) | ينشرها يوسف في موعدها، **فيجب أن يكون يوسف شغّالًا وقتها** |
| الحد | — | 100 منشور عبر الواجهة في 24 ساعة |

- **قبل الكتابة:** يقرأ آخر منشوراتك ليطابق أسلوبك، ويقرأ المنتج من متجرك (الاسم والسعر والصور) إن كان المنشور عن منتج. لا يخترع أسعارًا أو عروضًا.
- **المعاينة:** بطاقة تشبه المنشور: الصور، نص فيسبوك ونص إنستغرام إن اختلفا، الموعد. أزل العلامة عن أي منشور لا تريده ثم «طبّق المحدد».
- **الصور:** صورك تُحفظ في مكتبة يوسف على جهازك. إنستغرام يقبل JPEG من رابط عام فقط، فيرفع يوسف الصورة أولًا إلى صفحتك كصورة غير منشورة ويستخدم رابطها من خوادم فيسبوك، ثم يحذفها بعد النشر.
- **المجدولة:** تجدها في «حسابات السوشيال ← المنشورات المجدولة»، ويمكنك إلغاؤها. إن كان يوسف مغلقًا في موعد منشور إنستغرام وتأخر أكثر من ساعتين، لا ينشره تلقائيًا بل يعلّمه «فات موعده» لتقرر: «انشر الآن» أو «ألغِه».
- **ما لا يفعله:** لا يرسل رسائل، ولا يعلّق، ولا يحذف منشورات منشورة، ولا يطلق إعلانات.

## يوسف داخل VS Code

1. انقر **`install-vscode-extension.bat`**. يبني ملف `dist\yousef-ai.vsix` ويثبّته في VS Code.
   - إن لم يجد الأمر `code`: من VS Code افتح Extensions، ثم «...»، ثم **Install from VSIX**، واختر الملف.
2. أبقِ يوسف شغّالًا (`start.bat`)، ثم اضغط أيقونة يوسف في الشريط الجانبي (أو Ctrl+Alt+Y).

| داخل VS Code | النتيجة |
|---|---|
| لوحة يوسف الجانبية | محادثة تُرسل الملف المفتوح أو الكود المحدد مع طلبك |
| الزر الأيمن ← «يوسف: اشرح هذا» / «أصلح هذا» / «اسأل عن هذا الكود» | أوامر سريعة على التحديد أو الملف |
| «يوسف: افحص المشروع (ثغرات وأخطاء)» | يرسل المشروع كله للمدير التقني |
| «اعرض الفرق» | يفتح محرر الفروقات في VS Code بين الملف والاقتراح |
| «طبّق التعديلات» | يكتب يوسف الملفات، ويحدّثها VS Code تلقائيًا |

أول مرة يسألك يوسف إن كان مسموحًا له بالعمل على مجلد المشروع. الإضافة لا تحتوي ذكاءً بداخلها: كل شيء يمر عبر خادم يوسف المحلي بنفس النماذج والذاكرة والإعدادات.

## كيف يختار النموذج

لكل نوع مهمة توجيه تعدّله من الإعدادات:

| نوع المهمة | الافتراضي |
|---|---|
| المحادثة والأسئلة | محلي أولًا |
| تخطيط الخطوات | محلي أولًا |
| البرمجة | سحابي أولًا |
| التحليل | سحابي أولًا |
| الكتابة والمحتوى | سحابي أولًا |

- **عند الفشل:** إن تعطّل النموذج الأول، يجرّب التالي تلقائيًا.
- **بدون مفاتيح:** كل شيء يعمل محليًا.
- **النموذج المحلي للوكلاء أصحاب الأدوات** (مدير المتاجر، المدير التقني، ناشر السوشيال، المبرمج في مجلد): يجب أن يرد بصيغة JSON في كل خطوة. `qwen2.5:7b` يلتزم بها ويعمل كاملًا على كرت 6GB فهو سريع. `gpt-oss:20b` يعمل أيضًا (يرسل له يوسف التفكير بمستوى «منخفض»)، لكنه أبطأ على 6GB لأن معظمه يعمل على المعالج، وقد يتوقف Ollama إن امتلأت ذاكرة الكرت (مثلًا مع الصوت على كرت الشاشة). عندها يعيد يوسف المحاولة مرة، ثم يشرح لك ما تفعله.

## التعلّم

- **القواعد:** أضفها من الإعدادات، مثل «اكتب منشورات المتجر بلهجة عُمانية». تُعطى لكل الوكلاء في كل طلب.
- **التقييم:** بعد كل إجابة اضغط «أفادت» أو «لم تُفد» مع ملاحظة. يتذكّر يوسف ذلك في الطلبات المشابهة.

هذا تعلّم بالذاكرة، لا إعادة تدريب للنموذج.

## أين تُحفظ بياناتك

في `%LOCALAPPDATA%\YousefAI`، منفصلة لكل مستخدم ويندوز:

| الملف | المحتوى |
|---|---|
| `memory.db` | المهام، الخطوات، الدروس، المنشورات المجدولة والمنشورة |
| `settings.json` | الإعدادات (بدون مفاتيح) |
| `keys.dat` | المفاتيح المشفّرة |
| `media\` | الصور التي أرفقتها للمنشورات |
| `yousef.log` | سجل التشغيل لتتبع الأخطاء |

## خيارات التشغيل

```
start.bat --port 8780      منفذ آخر
start.bat --no-browser     بدون فتح المتصفح
start.bat --debug          سجل مفصّل
```

## الأمان

- **الشبكة:** الخادم يستمع على `127.0.0.1` فقط، فلا يصل إليه أي جهاز آخر على الشبكة.
- **المواقع الأخرى:** الطلبات التي تغيّر شيئًا تحتاج ترويسة خاصة، والخادم يرفض أي عنوان أو مصدر غريب. هذا يمنع أي موقع آخر مفتوح في المتصفح من التحكم بيوسف.
- **الميكروفون:** الصوت يُرسل فقط إلى خادم يوسف المحلي على جهازك.
